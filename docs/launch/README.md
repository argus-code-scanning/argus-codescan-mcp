Materials to promote Argus as open source.

| File | Use |
|------|-----|
| [show-hn.md](show-hn.md) | Copy/paste for [Show HN](https://news.ycombinator.com/submit) |
| [awesome-mcp-submission.md](awesome-mcp-submission.md) | PR text for awesome-mcp-servers and similar lists |
| [github-release-v0.2.0.md](github-release-v0.2.0.md) | GitHub Release notes for v0.2.0 |

## Before you launch

1. **GitHub Release** — publish `v0.2.0` with changelog (SARIF, policy, baseline diff, DB rules, secret remediation)
2. **PyPI / npm** — `pip install argus-scan` and `npm install argus-codescan` at latest versions
3. **Repo topics** — `mcp`, `security`, `sast`, `devsecops`, `sarif`, `semgrep`, `cursor`
4. **Screenshot** — add `docs/images/argus-scan-demo.png` to README (optional but helps HN)

## Suggested order

1. Publish packages + GitHub Release  
2. Open awesome-mcp-servers PR (easy win, permanent backlink)  
3. Post Show HN (Tuesday–Thursday, US morning)  
4. Cross-post Dev.to / LinkedIn with same narrative  
5. Enable GitHub Discussions for Q&A

## One-line pitch

> **Argus** — free, local security scanner with MCP for any IDE: 20+ tools, SARIF for GitHub, policy file, PR baseline diff. MIT.
